# Agent Memory & Experience Reuse

> [!abstract] 这组笔记研究什么？
> 如何让智能体从执行与评测中积累经验，并把经验转化为**更好的执行流程**或**下一次任务可用的记忆**。

## 先建立三个闭环

**AFlow：改进“以后如何做这一类题”。** 一个候选工作流在很多验证题上执行，评测结果指导下一次工作流修改。最后产物是可复用的执行程序。

**G-Memory：改进“下一道题能参考什么”。** 执行任务后保存案例、总结经验；新任务到来时检索相关记忆并放入智能体上下文。最后积累的是记忆库。

**AWM：改进“遇到相似子任务时有哪些操作套路可参考”。** 将历史网页操作提炼为抽象子流程；离线方式预先生成记忆，在线方式从已完成任务持续归纳。

| 比较轴 | AFlow | G-Memory | AWM |
| --- | --- | --- | --- |
| 外层输入 | 任务数据、评测器、工作流模板、算子库 | 新任务、历史任务与经验、既有 MAS | 新任务、网页观察、历史轨迹 |
| 经验单位 | 某个工作流修改及其分数变化 | 某次任务的轨迹、结果及跨任务规则 | 目标描述与变量化操作子流程 |
| 图的作用 | 搜索树记录工作流版本之间的修改关系 | 分层图组织任务、交互和抽象经验 | 主方法不依赖显式图数据库 |
| 主要反馈 | 验证集上的客观分数、错误日志 | 环境成败、任务评测、LLM 总结与相关性判断 | 在线模型评价；成绩由 benchmark 单独评测 |
| 执行新任务时 | 运行已选出的工作流 | 检索案例与经验，再运行原有系统 | 读取相关网站工作流，在当前观察下逐步选动作 |
| 自动更改协作拓扑 | 可通过工作流代码改变调用关系 | 主要通过记忆影响行为；不能等同于自动重写拓扑 | 未研究多智能体拓扑 |
| 参数训练 / RL | 无基础模型参数训练；MCTS 变体不是模型 RL 训练 | 无基础模型参数训练；规则加减分不是参数 RL | 无参数训练；离线生成记忆不等于 SFT |
| 最容易误读 | 搜索树节点被误当成单个 agent；少量改动被误读成只改一行 | 记忆图被误当成执行图；保存消息边被误当成检索时使用边 | 把上下文指南当执行宏；把 Mind2Web 步骤正确率当真实网页成功率 |

## 与研究设想的对应

- **经验优化 Harness**：AFlow 直接相关；G-Memory 提供可迁移的经验整理机制。
- **长期记忆与检索**：G-Memory 与 AWM 直接相关：前者组织多粒度经验，后者提炼程序性子流程；AFlow 的经验主要服务搜索器。
- **多智能体协作**：AFlow 可以改变调用与控制流程；G-Memory 可以给团队成员提供历史指导，但公开实现中角色投影是可选项。
- **RL / 参数蒸馏**：三篇都未完成。将外部经验变成训练样本或奖励，是后续研究扩展。
