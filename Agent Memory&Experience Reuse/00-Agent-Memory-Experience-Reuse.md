# Agent Memory & Experience Reuse

> [!abstract] 这组笔记研究什么？
> 如何让智能体从执行与评测中积累经验，并把经验转化为**更好的执行流程**或**下一次任务可用的记忆**。
> 当前收录 6 篇完整精读：AFlow、AWM、G-Memory、GPTSwarm、MemEvolve、EvolveR。前五篇改善模型外部系统；EvolveR 将外部原则记忆与 GRPO 参数训练结合。注意：GPTSwarm 的 RL 训练连边参数，EvolveR 的 RL 训练 LLM 策略参数。

## 先建立六个闭环

**AFlow：改进“以后如何做这一类题”。** 一个候选工作流在很多验证题上执行，评测结果指导下一次工作流修改。最后产物是可复用的执行程序。

**G-Memory：改进“下一道题能参考什么”。** 执行任务后保存案例、总结经验；新任务到来时检索相关记忆并放入智能体上下文。最后积累的是记忆库。

**AWM：改进“遇到相似子任务时有哪些操作套路可参考”。** 将历史网页操作提炼为抽象子流程；离线方式预先生成记忆，在线方式从已完成任务持续归纳。

**GPTSwarm：改进“团队内部谁应该参考谁”。** 用任务成绩更新跨 agent 连边概率；节点还可从历史成功执行中选择示例。最后产物包含外部数值策略，而基础 LLM 权重不变。

**MemEvolve：改进“系统应该怎样从经验中学习”。** 内层运行固定记忆程序并积累内容；外层诊断轨迹、生成新记忆程序、实际评测并选优。执行主循环和基础模型权重保持不变。

**EvolveR：改进“模型如何利用积累的经验做题”。** 离线将轨迹提炼为原则，在线主动检索原则与事实，随后用 GRPO 更新 LLM。经验文本默认屏蔽策略损失，不能把它理解成直接背下原则。

## GPTSwarm 补上的比较维度

- **与 AFlow**：AFlow 搜索可执行工作流代码；GPTSwarm 在预设节点和候选边上学习连接概率。
- **与 G-Memory**：G-Memory 的图组织历史记忆；GPTSwarm 的图直接决定当前任务的信息流和执行依赖。
- **与 AWM**：AWM 归纳可参考的程序性记忆；GPTSwarm 的节点示例来自近期执行，未实现同等的语义检索体系。
- **证据边界**：填字实验的 20 题同时用于优化和评测，指标是 best-state word accuracy；GAIA 没有运行图优化。HumanEval 公开在线代码以完整测试成败标签筛选示例，需与题面内部测试区分。

## MemEvolve 补上的比较维度

- **内容与机制分开**：G-Memory/AWM 在既定机制内积累经验；MemEvolve 进一步搜索记忆机制本身的 Python 实现。
- **代码修改范围**：与 AFlow 的工作流程序不同，MemEvolve 生成器明确限制修改记忆模块，不改变核心 agent loop。
- **两种图分开**：CerebraFusion 的图连接经验条目；GPTSwarm 的图连接运行操作。前者当前检索沿语义相似边扩展，并不沿已保存的同任务边扩展。
- **评测边界**：WebWalkerQA/xBench 提供跨任务架构迁移证据；GAIA Level 1 参与进化，不能将总体成绩视为完全未见测试。费用接近不代表延迟降低。

## EvolveR 补上的比较维度

- **双阶段连接**：前五篇重在外部系统，EvolveR 把原则记忆与真正的 LLM 参数 RL 接起来；没有修改记忆模块源码或多 agent 拓扑。
- **自蒸馏含义**：轨迹到自然语言原则属于外部信息提炼，默认不是教师 logits 或原则全文的监督蒸馏。
- **图与检索边界**：结构三元组作为记忆内容返回，主要召回依旧是向量搜索，未展示跨原则图遍历；效用分数用于维护，不等于检索入口显式融合重排。
- **证据边界**：3B 完整系统 0.382，评测禁用经验检索后 0.340；并非经验已完全进入参数。离线总结训练轨迹会提供标准答案，需要隔离测试集。

## 与研究设想的对应

- **经验优化 Harness**：AFlow、GPTSwarm 与 MemEvolve 直接相关；G-Memory 提供可迁移的经验整理机制。
- **长期记忆与检索**：EvolveR 直接相关；G-Memory 与 AWM 直接相关：前者组织多粒度经验，后者提炼程序性子流程；AFlow 的经验主要服务搜索器。
- **多智能体协作**：GPTSwarm 直接学习信息连接；AFlow 可以改变调用与控制流程；G-Memory 可以给团队成员提供历史指导，但公开实现中角色投影是可选项。
- **RL / 参数蒸馏**：GPTSwarm 用 REINFORCE 优化外部连边；EvolveR 用 GRPO 更新 LLM。EvolveR 默认只对生成动作计算策略损失，经验仍作为外部上下文；取消经验 mask 的消融不等于标准知识蒸馏。
